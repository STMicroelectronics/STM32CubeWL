STM32CubeWL Firmware Package v1.6.0 / 05-June-2026

Main Changes

  • HAL/LL Drivers updates
    • Update the following HAL drivers to get the latest corrections: DAC, CRC, SUBGHZ, RNG, TIM
  • Middlewares updates
    • Upgrade mbed-crypto Lib to use V3.6.6 (ST modified 2026-04-15)
    • Upgrade Sigfox to use V1.10.0
    • Upgrade STM32_Key_Management_Services to V1.2.5
    • Upgrade STM32_Secure_Engine to V2.5.5
    • Upgrade FreeRTOS to V10.6.2 (ST modified 2026-03-27)
    • Upgrade FatFS to R0.12c (ST modified 2026-04-03)
    • Upgrade LoRaWAN-LBM to V1.1.0
    • Upgrade SubGHz_Phy to V1.5.0
  • Projects updates
    • Update the system clock configuration to increase the LSE drive capability from LOW to HIGH
    • API call added to LoRaWAN_End_Node_LBM and LoRaWAN_Relay_LBM APPs for NUCLEO board. Class B can be enabled with LORAMAC_CLASSB_ENABLED set to 1.
    • Update the FLASH examples to simplify page handling, remove unnecessary OPTVERR clearing, and improve write protection verification.
